# 아키텍처

```
┌──────────── 목걸이 (XIAO nRF54L15 Sense) ────────────┐      ┌──────────────── Android ────────────────┐
│ PDM 마이크 → VAD → Opus 인코더 → 세그먼트 → SPI 플래시 │ BLE  │ SyncService → 파일 저장 → ACK            │
│ 마스터 버튼 → 이벤트 세그먼트 ─────────────────────┘ │◀────▶│ TranscribeWorker → STT → Room DB         │
│ 배터리 ADC / 충전 IC (200mA 고정)                     │ pull │ LocationRecorder (폰 GPS)                │
└───────────────────────────────────────────────────────┘      └──────────────────────────────────────────┘
```

- 기기는 **녹음하고 쌓기만** 해요. STT, 위치, 시각 복원은 전부 폰에서
- 전송은 폰이 당겨가는 방식(`protocol/ble-protocol.md`). ACK 받기 전엔 지우지 않음
- 실시간 스트리밍 없음. 폰이 근처에 있으면 **폰이 15분마다** 연결해서 가져감. 기기는 켜져 있는 동안 1초 간격으로 광고 (`decisions.md` #15)
- 플래시는 LittleFS, 세그먼트 하나 = 파일 하나 (`decisions.md` #18)

## 전력 예산 (추정 — 측정으로 갱신)

| 상태 | 전류 |
|---|---|
| System OFF | 수 µA (보드 측정치는 칩 단독 0.6µA보다 큼). 배터리 3.3V 아래에선 약 450µA (포럼 실측, `decisions.md` #8) |
| BLE 광고 (1초 간격, 상시) | 약 0.01–0.02mA (추정) |
| LED 깜빡임 (`decisions.md` #21) | 평균 0.01mA 이하 (켜질 때 약 0.9mA) |
| 대기 + 마이크 + VAD | 약 1mA대 |
| 말하는 중 (Opus 인코딩 추가) | 약 2–4mA |
| BLE 전송 중 (짧게) | 약 5–10mA |

250mAh ÷ 평균 2–5mA ≈ **2–5일**. 실제 값은 M5에서 측정.

## 저장 용량

16kbps Opus 기준 플래시 16MB ≈ **음성 약 2시간**. 폰 없이 오래 있으면 찬다 → 새 녹음을 멈추고 알림, 덮어쓰지 않음 (PRD D4, `decisions.md` #17).
