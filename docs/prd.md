## 1. 한 줄 정의

**목에 걸고 하루를 보내면, 저녁에 폰에서 "언제, 어디서, 무슨 말을 했는지" 타임라인으로 돌아볼 수 있는 개인용 기록 목걸이.**

## 2. 배경과 문제

- 하루에 나눈 대화, 떠오른 생각, 들은 정보는 대부분 기록되지 않고 사라져요.
- 폰 녹음 앱은 매번 꺼내서 켜야 하고, 하루 종일 켜두면 폰 배터리와 저장 공간이 버티지 못해요.
- 시중 AI 펜던트 제품은 클라우드 구독에 의존하고, 내 음성이 어디서 어떻게 처리되는지 통제하기 어려워요.

**Owl이 푸는 문제:** 신경 쓰지 않아도 하루가 기록되고, 기록은 내 폰에 남는 것.

## 3. 사용자

| 항목 | 내용 |
|---|---|
| 1차 사용자 | 제작자 본인 1명 |
| 사용 환경 | 등교·수업·작업·이동 등 일상. 폰(Android)을 대부분 몸에 지니고 다님 |
| 기술 수준 | 펌웨어를 직접 굽고 고칠 수 있음. 완제품 수준의 편의성보다 동작과 신뢰성이 우선 |

다른 사람이 쓰는 제품은 v1 범위가 아니에요(9장 비목표).

## 4. 핵심 사용 시나리오

**S1. 하루 착용**
아침에 목걸이를 걸고 나간다. 따로 조작하지 않는다. 내가 말하거나 주변에서 대화가 있으면 기기가 알아서 녹음하고, 조용할 땐 저장하지 않는다.

**S2. 자동 동기화**
폰이 근처에 있으면 목걸이와 폰이 알아서 연결해 녹음을 옮긴다. 앱을 열 필요가 없다. 폰을 두고 잠깐 나가도 목걸이에 쌓였다가 다시 가까워지면 옮겨진다.

**S3. 북마크**
"이건 나중에 다시 봐야겠다" 싶은 순간에 버튼을 짧게 누른다. 타임라인에서 그 지점에 북마크가 표시된다.

**S4. 잠깐 끄기**
녹음하면 안 되는 자리에서 버튼을 2초 눌러 녹음을 끈다(앱에서도 끌 수 있다). 다시 2초 누르면 켜진다. 목걸이를 아예 끄려면 5초 누른다.

**S5. 하루 돌아보기**
저녁에 앱을 열면 시간순 타임라인에 대화가 텍스트로 정리돼 있고, 각 구간에 장소가 붙어 있다. 위로 스크롤하면 지난 날짜로 이어진다. 원하는 구간은 음성으로 다시 들을 수 있다.

**S6. 충전**
밤에 USB-C로 충전한다. 다음 날 하루를 버틴다. 배터리가 다 닳아 꺼졌다면 충전 후 저절로 다시 켜진다.

## 5. 기능 요구사항

우선순위: **P0** = v1에 반드시 / **P1** = v1에 있으면 좋음 / **P2** = v1 이후

### 5.1 목걸이 (기기)

| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| D1 | 상시 녹음 | P0 | 착용 중 사람 목소리가 나면 사용자 조작 없이 녹음이 시작된다 |
| D2 | 무음 제거 (VAD) | P0 | 일정 시간 이상 조용한 구간은 저장하지 않는다 |
| D3 | 압축 저장 | P0 | 오디오를 Opus로 압축해 외장 플래시에 세그먼트 단위로 저장한다 |
| D4 | 유실 없는 보관 | P0 | 폰이 수신을 확인(ACK)하기 전에는 어떤 세그먼트도 지우지 않는다. 저장 공간이 가득 차면 새 녹음을 멈추고 LED·이벤트로 알리며, 폰이 가져가 공간이 생기면 다시 녹음한다 |
| D5 | 무선 전송 | P0 | 폰이 요청하면 BLE로 세그먼트를 보낸다. 중간에 끊기면 끊긴 위치부터 이어서 보낸다 |
| D6 | 시각 기록 | P0 | 모든 기록에 (부팅 번호, 부팅 후 경과 시간)을 남겨 폰이 실제 시각을 복원할 수 있게 한다 |
| D7 | 버튼 짧게: 북마크 | P1 | 짧게 누르면 그 시점이 북마크 이벤트로 기록된다 |
| D8 | 버튼 2초: 녹음 끄기/켜기 | P0 | 2초 누르면 녹음이 꺼지고, 다시 2초 누르면 켜진다. 앱 기기 화면에서도 끄고 켤 수 있다. 녹음을 꺼둔 상태는 기기가 꺼졌다 켜져도 유지된다. 상태가 바뀔 때 LED로 알린다 |
| D8a | 버튼 5초: 기기 끄기/켜기 | P1 | 5초 누르면 기기가 완전히 꺼진다(System OFF, 블루투스 포함). 꺼진 상태에서 5초 누르면 켜진다. 버튼으로 끈 기기는 저절로 켜지지 않는다 |
| D9 | 상태 표시 | P1 | LED(초록 1개)의 깜빡임으로 최소한 "녹음 켜짐 / 녹음 꺼짐 / 배터리 부족 / 저장 공간 가득"을 구분할 수 있다. 패턴은 `decisions.md` #21 |
| D10 | 배터리 보호 | P0 | 배터리가 3.6V 아래로 내려가면 LED·이벤트로 경고하고, 3.5V 아래로 내려가면 기록을 정리하고 System OFF로 들어간다. 이렇게 꺼진 경우에만 1시간마다 깨어나 전압을 확인해 충전됐으면 저절로 켜진다 |
| D11 | 충전 | P0 | USB-C로 충전된다. 충전 중에도 동작한다 |
| D12 | 펌웨어 업데이트 | P1 | USB로 업데이트할 수 있다. 무선(OTA) 업데이트는 P2 |

### 5.2 앱 (Android)

| ID | 기능 | 우선순위 | 완료 기준 |
|---|---|---|---|
| A1 | 기기 등록 | P0 | 처음 한 번 목걸이를 등록하면 이후 다시 고를 필요가 없다 |
| A2 | 자동 동기화 | P0 | 목걸이가 범위 안에 있으면 앱을 열지 않아도 15분마다 동기화된다. 앱이 최근 앱 목록에서 지워져도 동작한다 |
| A2a | 수동 동기화·연결 | P1 | 기기 화면의 "지금 동기화"로 바로 동기화한다. 연결 끊김 상태면 연결 버튼으로 다시 연결을 시도한다. 앱을 켤 때마다 연결을 다시 시도한다 |
| A3 | 저장 후 확인 | P0 | 받은 세그먼트를 폰 저장소에 쓴 **뒤에** ACK를 보낸다 |
| A4 | 시각 복원 | P0 | 연결할 때마다 시각을 맞추고, 모든 기록을 실제 시각으로 변환한다 |
| A5 | 위치 기록 | P0 | 폰 GPS로 위치를 주기적으로 기록한다. 앱 프로세스가 없어도 기록된다 |
| A6 | 음성 → 텍스트 | P0 | 받은 녹음을 **폰 안에서(온디바이스)** 한국어 텍스트로 변환한다. 클라우드 STT는 쓰지 않는다 (`decisions.md` #10) |
| A7 | 타임라인 | P0 | [시각 · 장소 · 텍스트]를 시간순으로 보여준다. 최신 기록이 맨 아래이고, 위로 스크롤하면 날짜를 넘어 이어진다(무한 스크롤). 헤더에 현재 스크롤 위치의 날짜를 표시하고, 목록의 오늘 구분선은 "오늘"로만 쓴다. 녹음이 없는 구간은 표시하지 않는다 |
| A8 | 음성 재생 | P1 | 타임라인 항목을 누르면 해당 구간 음성을 재생한다. 재생 위치(재생·탐색 바 이동)에 맞는 문장이 강조되고, 되감기/빨리감기는 이전/다음 문장으로 이동한다. 음성 파일이 삭제된 뒤에도 같은 플레이어로 문장 탐색은 되고 재생 버튼만 비활성화된다 |
| A8a | 처리 상태 표시 | P1 | 아직 처리 중인 기록은 "녹음 파일 받는 중"(기기→폰) / "텍스트 추출 중"(폰에서 STT) 상태와 진행 표시를 보여준다. 텍스트가 없어도 음성이 폰에 있으면 눌러서 재생할 수 있다 |
| A9 | 북마크 표시 | P1 | 버튼으로 남긴 북마크가 타임라인·상세에서 보인다(과하게 강조하지 않음). 북마크만 모아 보는 필터가 있다 |
| A10 | 기기 상태 | P1 | 전원 상태(켜짐 / 연결 끊김)와 녹음 상태(켜짐 / 꺼짐)를 따로 보여준다. 연결 끊김은 동기화 요청이 재시도까지 실패하면 바로 표시한다(꺼진 기기와 멀리 있는 기기는 구분하지 않음). 녹음 끄기/켜기 스위치를 둔다. 배터리 잔량·남은 시간 추정, 저장 공간(사용량 / 전체 MB), 미전송 녹음 개수, 마지막 동기화 시각, 펌웨어 버전을 보여준다. 전압·시각 동기화 같은 내부 정보는 보여주지 않는다 |
| A11 | 검색 | P1 | 텍스트로 지난 기록을 검색한다. 기간·장소·북마크·보존됨으로 거를 수 있다 |
| A12 | 하루 요약 | P2 | 하루 대화를 요약해 보여준다 |
| A13 | 내보내기 | P1 | 기록(텍스트·시각·장소)을 파일로 내보낸다 |
| A14 | 음성 보관 기간 | P1 | 설정에서 음성 보관 기간을 고른다(7일 / 30일 / 90일 / 지우지 않음 / 텍스트 추출 후 바로 삭제, 기본 30일). 기록 상세 메뉴에서 "음성 보존"을 켜면 기간이 지나도 지우지 않는다. 텍스트는 항상 남는다 (`decisions.md` #11) |
| A15 | 여러 기기 | P2 | 목걸이를 여러 대 등록하고 기기 화면에서 전환한다 |
| A16 | 사용 설명 | P1 | 설정 › 사용 설명에 버튼 사용법(짧게 / 2초 / 5초)과 LED 의미를 적는다. 기기 화면에는 상태만 보여주고 사용법 문구는 넣지 않는다 |

| N8 | 프라이버시 | 음성·위치·텍스트는 **기기와 내 폰에만** 존재. 외부 전송 없음. 예외는 사용자가 직접 내보낸 파일(A13)뿐 | `decisions.md` #10, #22. 앱은 Android 자동 백업·기기 간 이전을 끈다. 앱 스플래시 화면과 설정 › 개인정보 처리 방침에 이 원칙을 문구로 표시 |
| N9 | 안전 | KC 인증 배터리, 충전 1C 이하, 과방전 차단 | `decisions.md` #7, #8 |

## 7. 시스템 구성 (요약)

```
목걸이: 마이크 → VAD → Opus → 플래시 ──BLE(폰이 요청)──▶ 폰: 저장 → ACK → STT → 타임라인
                                                          폰 GPS ─────────────┘
```

- 하드웨어: XIAO nRF54L15 **Sense** + W25Q128 16MB 플래시 + 250mAh LiPo + 버튼 1개 (`hardware/`)
- 펌웨어: Zephyr / nRF Connect SDK (`firmware/`)
- 앱: Android, Kotlin (`android/`)
- 통신: 자체 BLE 프로토콜 v1 (`protocol/`)

자세한 내용은 [architecture.md](architecture.md).

## 8. 버전 정의

**v1 완료 =** 하루(16시간) 착용 후, 앱 타임라인에서 그날의 대화를 시각·장소와 함께 텍스트로 확인할 수 있고, 그 과정에서 유실된 녹음이 없다.

마일스톤별 진행은 [roadmap.md](roadmap.md).

## 9. 비목표 (v1에서 하지 않는 것)

- 기기 안에서 STT·요약 (칩 성능상 불가, 폰이 담당)
- 실시간 스트리밍, 실시간 자막
- 기기 자체 GPS
- iOS 앱
- 여러 사용자, 계정, 클라우드 동기화
- 화자 구분 (P2 이후 검토)
- 방수, 완제품 수준의 외관

| 위험 | 영향 | 대응 |
|---|---|---|
| 다른 사람의 대화가 녹음됨 | 법적·윤리적 문제 | 대화 당사자가 아닌 타인 간 대화를 녹음하는 것은 통신비밀보호법상 문제가 될 수 있음(법률 자문 아님). D8 녹음 끄기를 P0로 두고 버튼으로 바로 끌 수 있게 한 이유. 원본은 기기와 내 폰에만 보관 |
| 폰 없이 오래 있으면 플래시가 참 | 녹음 누락 | N5 동기화 주기, D4(가득 차면 녹음 멈춤) |
| 배터리 수명이 추정보다 짧음 | N1 미달 | M5에서 실측, 마이크·안테나 스위치 전원 관리 |
| 보드가 3.3V 아래에서 전류 급증 (포럼 실측 약 3µA → 450µA) | 배터리 과방전 | D10 (3.5V 차단). 꺼진 채 몇 주 방치하면 3.3V 아래로 내려가 빠르게 닳으므로, 사용 설명(A16)에 "오래 안 쓰면 충전해서 보관" 안내 |
| Android 백그라운드 제한 | 자동 동기화 실패 | CDM + 포그라운드 서비스, 삼성 "열린 상태로 유지" 안내 |
| 납땜 도구 출력 부족 (10W) | BAT 패드 납땜 실패 | 플럭스·예비 납땜, 안 되면 전용 인두 구매 |

## 12. 용어

| 용어 | 뜻 |
|---|---|
| 세그먼트 | 녹음의 저장·전송 단위. 헤더 32바이트 + Opus 프레임들 |
| VAD | Voice Activity Detection. 소리가 사람 말인지 판별해서 무음을 걸러냄 |
| ACK | 폰이 "잘 받아서 저장했다"고 기기에 알려주는 확인 |
| 북마크 | 목걸이 버튼을 짧게 눌러 남기는 표시. 예전 이름 "순간 표시" |
| 녹음 끄기 | 버튼 2초(또는 앱). 기기는 켜져 있고 동기화도 되지만 새로 녹음하지 않음. 예전 이름 "일시정지" |
| 기기 끄기 | 버튼 5초. System OFF로 완전히 꺼짐. 블루투스도 꺼져 폰과 연결되지 않음 |
| CDM | Android CompanionDeviceManager. 등록한 기기가 가까이 오면 앱을 깨워줌 |
| System OFF | nRF 칩의 가장 깊은 절전 상태. 버튼이나 내장 타이머(GRTC)로만 깨어나고, 깨어나면 재부팅함 |
